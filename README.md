# Inside


Inside 是一个安静的 AI 深度思考伙伴原型。它使用浏览器自带的语音识别，并把完成的思考保存在当前浏览器本地。


## 启动（最简单）


双击 `启动 Inside.command`，浏览器会直接打开 Inside。


这个版本不需要启动服务器，也不需要保留终端窗口。


如果系统第一次询问是否允许打开，请选择允许。


## 也可以直接打开


直接双击文件夹里的 `index.html`。


建议使用 Chrome 以获得更好的中文语音识别支持。


## 当前版本


- 每日三个开场问题
- 浏览器语音识别与文字输入
- 2–4 轮温和追问
- 思考总结
- 浏览器本地保存
- 过往思考页面


这是无后端的第一版原型。AI 追问和总结目前由本地规则生成，未来可以直接替换为真正的 AI 接口。



更新记录：新增“换一组问题”功能。
