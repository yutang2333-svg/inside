# Inside

Inside 是一个安静的思考记录工具。它使用浏览器自带的语音识别，把完成的记录保存在当前浏览器本地，并可将完整记录导出给 GPT 深入分析。

## 启动（最简单）

双击 `启动 Inside.command`，浏览器会直接打开 Inside。

这个版本不需要启动服务器，也不需要保留终端窗口。

如果系统第一次询问是否允许打开，请选择允许。

## 也可以直接打开

直接双击文件夹里的 `index.html`。

建议使用 Chrome 以获得更好的中文语音识别支持。

## 当前版本

- 每日三个开场问题
- 可以随时换一组开场问题
- 浏览器语音识别与文字输入
- 连续记录真实表达
- 可修改的记录标题与完整原文
- 复制、分享或打开 ChatGPT 进行深入分析
- 浏览器本地保存
- 过往思考页面

这是无后端的第一版原型。Inside 不在本地猜测或分析用户，未来可将独立的导出模块替换为真正的 AI 接口。
